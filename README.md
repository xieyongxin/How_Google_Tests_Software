## 阅读方式

1. 阅读对应目录的 `README.md`，理解章节要点与 Demo 的映射。
2. 阅读 `DEVELOPMENT_PROCESS.md`，了解 SWE、SET 和构建工程角色的协作过程。
3. 使用 `git log --reverse --oneline` 查看中文提交历史。
4. 使用 `git show <提交>` 观察每个阶段引入的代码和测试。
