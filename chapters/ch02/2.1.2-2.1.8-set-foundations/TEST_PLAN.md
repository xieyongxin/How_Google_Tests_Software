# 原型阶段测试计划

## 范围

本计划只覆盖概念验证的稳定核心：URL 校验和内存索引。不覆盖 HTTP、RPC、持久化、并发和部署。

## 测试层级

| 测试 | 规模 | 目的 |
| --- | --- | --- |
| `AddUrlPrototypeTest` | small | 验证有效 URL、无效 URL 和索引不污染 |
| `DesignDocumentCheckTest` | tool check | 验证设计文档具备后续开发所需的最小信息 |

## 场景

- `https://www.example.com` 和 `http://localhost:8080/path` 应成功写入。
- `ftp://...`、缺少主机、空字符串和空白字符串应被拒绝。
- 重复提交同一个 URL 不应产生重复索引项。
- 任何失败结果都不应改变已存在的索引内容。

## 后续实验的测试边界

正式立项后增加 Protobuf 序列化兼容性、后端错误、超时、HTTP 链路和文件索引测试；这些测试放在 2.1.9 实验中，避免概念原型承担不必要的基础设施。
